# 🚀 Quick Windows Installation (5 minutes)

## Prerequisites
- ComfyUI installed at: `C:\Users\shade\ComfyUI`
- Git installed (download: https://git-scm.com/download/win)

## Quick Install Steps

### 1. Open PowerShell in ComfyUI folder
```
cd C:\Users\shade\ComfyUI
```

### 2. Install ControlNet Aux (provides MLSD, Lineart, Canny nodes)
```
git clone https://github.com/Fannovel16/ComfyUI-ControlNet-Aux.git custom_nodes\ComfyUI-ControlNet-Aux
```

### 3. Install ComfyUI Manager (optional but recommended)
```
git clone https://github.com/ltdrdata/ComfyUI-Manager.git custom_nodes\ComfyUI-Manager
```

### 4. Download ControlNet Union Pro Max (2.5 GB)
- Go to: https://huggingface.co/xinsir/controlnet-union-sdxl-1.0
- Download: `checkpoint.pth`
- Rename to: `controlnet_union_sdxl_promax.pth`
- Move to: `C:\Users\shade\ComfyUI\models\controlnet\`

### 5. Restart ComfyUI
```
# Stop ComfyUI (Ctrl+C), then:
python main.py --listen 0.0.0.0
```

### 6. Load workflow
Open http://localhost:8188 → Load `floorplan_workflow_2025.json`

## Verify Installation

After restarting ComfyUI, you should see:
- ✅ "Manager" tab in sidebar (if installed)
- ✅ No red nodes in workflow
- ✅ MLSD, Lineart, Canny available as preprocessor options
